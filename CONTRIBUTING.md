# Contribuir a FluxTime

¡Gracias por interesarte en FluxTime! Las contribuciones pueden incluir correcciones, mejoras de compatibilidad, documentación y sugerencias visuales.

## Antes de empezar

- Lee el [README](README.md) para conocer el proyecto.
- Comprueba que tienes Python 3.
- FluxTime está pensado para seguir siendo sencillo y no requiere dependencias externas.

## Proponer un cambio

1. Abre un Issue para describir un error o una mejora importante.
2. Crea una rama para tu trabajo.
3. Mantén los cambios enfocados y explica por qué son útiles.
4. Prueba el programa manualmente en una terminal compatible.
5. Envía un Pull Request con un resumen claro de los cambios y las pruebas realizadas.

## Guía de estilo

- Conserva la compatibilidad con la biblioteca estándar siempre que sea posible.
- Evita añadir dependencias para tareas que Python ya puede resolver.
- Mantén los textos de interfaz en español, salvo que el proyecto adopte una política distinta.
- Respeta el diseño Midnight Plasma y la legibilidad de la terminal.
- No afirmes que una función fue probada en sistemas donde no se ejecutó.

## Informes de errores

Incluye tu sistema operativo, versión de Python, terminal utilizada, pasos para reproducir el problema y el resultado esperado. No publiques información privada en los reportes.

## Licencia de las contribuciones

Al enviar una contribución, aceptas que se distribuya bajo la licencia MIT del proyecto, salvo que se indique explícitamente lo contrario y el mantenedor lo acepte.
