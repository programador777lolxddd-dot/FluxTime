# Política de seguridad

## Reportar una vulnerabilidad

Si detectas un posible problema de seguridad relacionado con FluxTime, informa al mantenedor de forma responsable mediante los canales privados de contacto que estén disponibles en el perfil de GitHub.

Si no existe un canal privado habilitado, evita incluir datos personales o detalles sensibles en un Issue público. Describe el problema de forma mínima y solicita una vía privada de comunicación.

## Alcance

FluxTime es una aplicación de terminal local que utiliza la biblioteca estándar de Python y no necesita conexión a internet, credenciales ni servicios externos. Aun así, los errores de código y de empaquetado pueden afectar a quienes lo ejecuten.

## Al informar

Cuando sea posible, incluye:
- Una descripción del problema y su impacto.
- Pasos para reproducirlo.
- Sistema operativo y versión de Python.
- Una posible solución, si la conoces.

No incluyas contraseñas, tokens ni información privada en el reporte.
